数据结构：哈希表的原理与实现

一、什么是哈希表？

哈希表（Hash Table），也叫散列表，是根据关键码值（Key-Value）而直接进行访问的数据结构。

它通过把关键码值映射到表中一个位置来访问记录，以加快查找的速度。这个映射函数叫做散列函数（Hash Function），存放记录的数组叫做哈希表。

二、核心思想

如果不使用哈希表，我们要找一个数据，通常需要遍历数组（时间复杂度 (O(n))）。而哈希表通过计算哈希值：
$$ index = hash(key) \bmod table_size $$
直接定位到数据应该存放的数组下标，从而实现平均时间复杂度 (O(1)) 的查找。

三、哈希冲突（Collision）

因为数组的长度是有限的，而输入的数据是无限的，所以必然会有不同的 key 计算出相同的 index。这就是哈希冲突。

常见的解决冲突的方法：

  1. 开放定址法（Open Addressing）：线性探测、平方探测。
  2. 链地址法（Chaining）：把冲突的元素放在一个链表里（C++ 的 std::unordered_map 就是这么干的）。

四、C++ 代码实现（链地址法）

#include <iostream>
#include <vector>
#include <list>
using namespace std;

class HashTable {
private:
    int size;
    vector<list<pair<int, int>>> table; // 拉链法

    int hashFunc(int key) {
        return key % size;
    }

public:
    HashTable(int s) : size(s) {
        table.resize(size);
    }

    void insert(int key, int value) {
        int index = hashFunc(key);
        table[index].push_back({key, value});
    }

    int search(int key) {
        int index = hashFunc(key);
        for (auto& p : table[index]) {
            if (p.first == key) return p.second;
        }
        return -1; // 没找到
    }
};

int main() {
    HashTable ht(10);
    ht.insert(1, 100);
    ht.insert(11, 200); // 1 和 11 会发生冲突，放在同一个链表里
    cout << "查找 key=11: " << ht.search(11) << endl;
    return 0;
}
